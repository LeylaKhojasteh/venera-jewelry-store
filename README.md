## چرا این فروشگاه فروش را جدی می‌گیرد

خیلی از فروشگاه‌ها محصول را در یک ردیف عکس و یک دکمه خلاصه می‌کنند. ونرا طور دیگری شروع می‌شود: با یک صحنهٔ سه‌بعدی، یک تایپوگرافی آرام و فضایی که محصول را شبیه یک قطعهٔ واقعی نشان می‌دهد.

| تجربهٔ اول | روایت محصول | مدیریت فروش |
| --- | --- | --- |
| هیرو سه‌بعدی با گردنبند، دستبند، گوشواره و انگشتر؛ ورود آرام و تمیز، بدون شلوغی. | هر محصول صفحهٔ خودش را دارد: تصویر بزرگ، داستان، جنس، اندازه، موجودی و پیشنهادهای هم‌دسته. | پنل مدیریت کامل برای محصول، عکس، واریانت، دسته، سفارش، مشتری و پیام‌ها. |

## آنچه پشت صحنهٔ فروش را ساده می‌کند

پنل مدیریت فقط یک صفحهٔ آمار نیست؛ ابزار روزمرهٔ صاحب فروشگاه است:

- **مدیریت محصولات:** ساخت و ویرایش محصول، قیمت، موجودی، توضیحات و وضعیت نمایش
- **عکس محصول:** آپلود مستقیم تصویر و انتخاب تصویر اصلی
- **واریانت‌ها:** اندازه، رنگ یا پرداخت، با موجودی مستقل برای هر گزینه
- **دسته‌بندی‌ها:** چیدمان دسته‌ها و نمایش تعداد محصولات
- **سفارش‌ها:** مشاهده، تغییر وضعیت و پیگیری سفارش‌ها
- **مشتری‌ها:** حساب‌ها، نشانی‌ها و سابقهٔ خرید
- **پیام‌ها:** پیام‌های فرم تماس، همراه با وضعیت خوانده‌شده
- **فروش و تخفیف:** قیمت مقایسه‌ای، درصد تخفیف و نشان پرفروش

همهٔ این‌ها از یک پنل، بدون نیاز به دست‌زدن به کد.

## طراحی که اعتماد می‌سازد

- **راست‌به‌چپ واقعی:** تایپوگرافی، فاصله‌ها و چیدمان برای فارسی تنظیم شده‌اند، نه ترجمه‌شده از یک قالب لاتین.
- **تم روشن و تیره:** هر دو تم با پالت کرم، زرشکی و مسی هماهنگ شده‌اند.
- **موبایل جدی:** هیرو، کاتالوگ، صفحهٔ محصول، سبد و پنل مدیریت برای لمس و صفحهٔ کوچک بازطراحی شده‌اند.
- **حرکت با هدف:** ورود نرم، نمایش سه‌بعدی و انتقال‌های کوتاه؛ با احترام به `prefers-reduced-motion`.
- **آمادهٔ دیده‌شدن:** عنوان و توضیح هر صفحه، Open Graph، sitemap، robots و دادهٔ ساختاریافتهٔ محصول.
- **تصویر بهینه:** تصاویر محلی، ابعاد ثابت و بارگذاری تدریجی؛ بدون وابستگی به سرویس خارجی.

| --- | --- |
| فرانت‌اند | Next.js 16 (App Router)، React 19، TypeScript |

## راه‌اندازی برای توسعه‌دهنده

```bash
git clone <repository-url>
cd venera-jewelry-store
npm install
cp .env.example .env
npx prisma migrate dev
npm run db:seed
npm run dev
```

برای اجرای تست‌ها:

```bash
npx playwright install msedge
npx playwright test
```

متغیرهای اصلی محیط:

```env
DATABASE_URL=
AUTH_SECRET=
NEXT_PUBLIC_SITE_URL=
RESEND_API_KEY=
EMAIL_FROM=
```

برای دیپلوی، پروژه روی Vercel با پایگاه دادهٔ Neon اجرا می‌شود. مایگریشن‌ها با `DATABASE_URL_UNPOOLED` و `prisma migrate deploy` اعمال می‌شوند.
